# iActive Services

iActive Services by iActive Services.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/i-active-wap/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **iActive Services** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/i-active-wap/releases/latest) and reinstall.
